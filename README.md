## 왜 만들었나

국내 은퇴 계산기는 대부분 수익률과 수명을 고정한 단순 계산이고, 세금·건강보험료가 빠져 있어 결과가 낙관적입니다. 해외 도구(Boldin, ProjectionLab)는 확률 시뮬레이션을 쓰지만 미국 제도 기준입니다. 이 프로젝트는 **한국 제도 + 확률 모델 + 계리 모델**을 하나로 묶어 그 빈자리를 채웁니다.

## 이렇게 동작합니다

```
① 단계별 입력 (20세부터): 은퇴 시점 → 자산·소득·저축 → 기본생활비 → 여행 예산 → 연금 → 남길 자산 → 투자 성향 → 최종 확인
② 1만 개 시나리오: 금리·물가·주가(연결된 확률과정) × 부부 각자의 수명·간병(다중상태 모델)
③ 현금흐름: 은퇴 전 저축 → 은퇴 후 기본생활비 우선, 여유가 있을 때만 여행 예산 지출
④ 세금·건보료·보유세·상속세 반영
⑤ 결과: Income Gap, 목표별 달성 확률, 필요 금융자산·필요 저축액, "직접 바꿔보기"(은퇴 시기·저축·생활비·국민연금·투자 성향 슬라이더, 변화 곡선, 주택연금·집 줄이기 비교), "상품 추가해 보기"(주식·예금·연금·보험)
```

## 차별점

1. **목표 기반 구조** — 기본생활(지켜야 할 목표), 여행·취미(조정 가능한 목표), 남길 자산을 나누고, 나쁜 시나리오에서는 선택 지출부터 줄이는 가드레일 규칙을 적용 (보호선 = 생존확률 가중 기대 부족분 현가)
2. **한국 제도** — 국민연금 조기·연기수령, 사적연금 1,500만원 분리과세, 금융소득종합과세, 건강보험료(지역/직장, 피부양자), 재산세·종부세, 상속·증여세
3. **계리 모델** — 통계청 2024 완전생명표 + 코호트 사망률 개선(연령별 연간 0.3~2.5%, 통계청 추이로 검증), 부부 공동생존, 간병 다중상태 마르코프(건강 → 경증 → 중증 → 사망, 장기요양 통계로 보정), 연금 상품(종신·부부형·보증기간·체증·거치형) 수지상등 가격, 생명표 사망률 보존 보정
4. **확률 경제 모델** — ECOS 실데이터로 추정한 실질금리·물가 OU 과정과 피셔 연결, 2요인 채권 가격 해석해, 1년 금리 적분의 정확한 결합분포, 폭락 점프, 파라미터 불확실성, 운용보수
5. **통계적으로 정직한 비교** — 공통 난수 위에서 경로별 차이로 신뢰구간을 계산해 "차이 있음 / 없음"을 판정

> **v33 (2026-10-13):** 모델이 아니라 **쓸 수 있게 만드는 껍데기**를 붙였습니다. 고객 입력 저장·복원, 입력과 모델 버전을 해시한 **재현용 계산 ID**, 고객에게 남길 **두 장짜리 상담 리포트**(HTML, 브라우저 인쇄로 PDF), 그리고 "왜 모자라는지"를 보여주는 **워터폴 그래프**입니다. 설계사가 고객과 마주 앉는 자리(B2B2C)에서 업무 단위는 상담 한 건이고 산출물은 리포트라는 판단입니다.

> **v32 (2026-10-13):** v31에서 한계로 적어 둔 근사식 세 개를 실제 기준으로 교체했습니다. 기초연금 **국민연금 연계감액을 법정 산식**(250% 산식 / A급여 산식 중 큰 값, 부가연금액 하한)으로 바꾸고 소득역전방지 감액을 추가, 기본재산액을 **지역 3구간**(대도시·중소도시·농어촌) 선택으로, 사별 효과를 **Moon et al.(2011) 메타분석**(226만 명, 연령 보정)으로 재보정했습니다. 국내 혼인상태별 사망률(사별/유배우 4.2배)은 연령 보정이 없어 쓰지 않았습니다.

> **v31 (2026-10-13):** 모형을 키우는 대신 **영향 없는 복잡도를 덜어내고 계산이 맞는지 증명**했습니다. 결정론적 극한에서 닫힌식과 상대오차 1e-7 안에서 일치함을 테스트로 고정했고(`scripts/benchmark_analytic.py`), 구성요소별 영향도를 측정해(`scripts/ablate.py`) 몬테카를로 오차 안에 있던 경제 시나리오 생성기 하나를 없앴습니다. 모형 코드 1,874줄 → 1,643줄(−12%), 모듈 14 → 11개. 오차 예산(`scripts/error_budget.py`): 난수 오차 ±0.7%p vs 주식 위험프리미엄 1σ 14%p — **결과는 숫자 하나가 아니라 범위로 읽어야 합니다.**

> **참고 (v28~v30):** 아래 예시 수치는 v27 기준입니다. v28에서 유족연금·기초연금이 들어가 기본생활 유지 확률이 전반적으로 올라갔고(대표 가구에서 +10~28%p), v30에서 장수 불확실성으로 꼬리 위험이 커졌습니다. 최신 수치는 웹 앱에서 확인하세요. 표의 '변화량'은 방향·크기 순서를 보는 용도입니다.

## 결과 예시 (52세·50세 부부, 60세 은퇴, 금융자산 5억, 월 저축 150만원 · 가정값 임시)

- 기본생활비 월 300만원 + 여행 연 1,200만원 − 연금 월 160만원 → **투자자산이 매달 메워야 할 돈 240만원**
- 목표 달성: 기본생활 유지 **48%**, 여행·취미 충족 **60%**, 1억 남기기 **37%**

| 무엇을 바꾸면 | 기본생활 유지 확률 변화 (95% 신뢰구간) |
|---|---|
| 은퇴 2년 늦추기 | **+11.8%p** (±0.6) |
| 생활비 10% 줄이기 | +9.2%p (±0.6) |
| 투자 성향 성장형 | +6.4%p (±0.5) |
| 월 저축 50만원 늘리기 | +4.8%p (±0.4) |
| 투자 성향 보수형 | −13.9%p (±0.7) |

| 위기 상황 | 기본생활 유지 확률 변화 |
|---|---|
| 은퇴 첫해 주가 −40% | −15.7%p |
| 은퇴 10년 뒤 주가 −40% | −10.4%p |
| 3년 연속 물가 6% | −5.6%p |
| 예상보다 오래 삶 (사망률 −20%) | −3.6%p |
| 간병 발생 2배 | −1.0%p |

- 이 가구에서는 **은퇴 시점이 가장 강력한 수단**이고, 같은 폭락도 **은퇴 직후**에 올수록 치명적입니다(수익률 순서 위험).
- 지출을 "기본 + 선택"으로 나누면, 같은 총지출이라도 고정 지출일 때보다 고갈확률이 낮아집니다(53.9% → 47.6%).
- 가장 큰 불확실성은 **주식 위험프리미엄**입니다. 추정 범위(5.2% ± 1.4%p) 안에서 기본생활 유지 확률이 36%~59%로 움직입니다. 그래서 절대값보다 선택지 간 차이를 보는 것이 중요합니다.

**20~40대 (30·29세 맞벌이, 연 소득 9,000만원, 저축률 15%, 퇴직연금 적립, 국민연금 자동 추정 월 243만원)**

- 기본생활 유지 **82%**, 여행·취미 충족 **91%**
- 은퇴 전 저축으로 기본생활 **10번 중 9번**을 지키려면: 세전 소득의 **23%**(첫해 월 약 171만원)
- 무엇을 바꾸면: 월 저축 50만원 늘리기 +8.1%p, 은퇴 2년 늦추기 +6.7%p, 생활비 10% 줄이기 +6.1%p · 퇴직연금이 없다면 −23.0%p
- 큰 지출을 넣으면: 48세부터 자녀 대학 연 1,000만원×8년 −4.7%p · 35세 6억 집 구입(대출 60%·30년, 전세금 2억 회수) −10.7%p(대출 25년이면 −6.7%p, 그 집으로 월세 80만원을 안 내게 되면 +8.1%p) · 둘에 58세 결혼자금 1억까지 −25.8%p

**집은 있고 현금은 적은 가구 (65·63세 부부, 금융자산 3억, 집 시세 7억·공시 5억, 기본생활비 월 250만원 + 여행 연 1,200만원)**

| 주택 활용 | 기본생활 유지 | 여행·취미 충족 | 3억 남길 확률 | 비고 |
|---|---|---|---|---|
| 그대로 | 13% | 33% | 100% | — |
| 주택연금 지금 가입 (63세) | 70% (+56.5%p) | 94% | 43% | 월 165만원 |
| 주택연금 70세 가입 | 77% (+63.7%p) | 91% | 47% | 월 215만원 (오늘 가치) |
| 70세에 절반 가격 집으로 이사 | 71% (+57.9%p) | 88% | 99% | 현금 3.4억 확보 |

- 집이 자산의 대부분인 가구는 **집을 활용하느냐가 가장 큰 선택**입니다. 주택연금은 노후 안정성을, 집 줄이기는 상속까지 함께 지키는 쪽으로 맞교환이 갈립니다.

## 검증

- OU·Vasicek 정확 이산화: 장기 평균·표준편차가 이론값과 일치 (금리 2.99%/1.84% vs 3.00%/1.83%)
- 채권 가격: Vasicek 해석해 0.87706 vs 몬테카를로 0.87723, 2요인 해석해 0.87553 vs 0.87518
- 1년 금리 적분 5×5 결합공분산: 해석해 vs 세밀 시뮬레이션 상관 최대 오차 0.005
- 사망률: 통계청 2024 완전생명표, 모델 기대여명이 공표치와 일치 (0·60·65·80세, 남녀 모두)
- 간병 다중상태 모델에서도 60세 남성 기대여명 보존 (생명표 23.7년 → 23.9년)
- OU 최우추정: 가상 데이터에서 장기 평균·변동성 복원 (회귀 속도는 소표본 과대추정 확인 → 실데이터 추정에서 편의 보정)
- 주식: KOSPI 2000-02~2026-08 월별 데이터로 변동성·폭락 빈도·금리 상관 추정, 위험프리미엄은 데이터와 해외 연구치(Damodaran)를 베이즈 결합
- 집값: 한국부동산원 주택가격지수(ECOS, 2013~) — 평활 보정 후 변동성 10%, 실질 상승률 1.25%±1.18%p
- 금리·물가: ECOS 2000-01~2026-08 월별 데이터로 추정 (물가 장기평균 2.47%±1.02%p, 실질금리 0.73%±0.74%p)
- 선택지 비교는 경로별 차이로 신뢰구간 계산 (독립 가정 ±1.38%p → ±0.44%p)
- 회귀 테스트 15개를 커밋마다 자동 실행 (대표 가구 결과 범위, 방향성, 이론값, 생명표·간병·주택연금 수치)
